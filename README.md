EDITH (`edith`)

An AI Cowork Assistant designed to run locally on your PC.


🚀 About

EDITH is a local AI cowork assistant built to streamline daily tasks, provide intelligent assistance, and maintain productivity, all while keeping your data private and running locally on your hardware.


🛠️ Tech Stack & Languages

Python

JavaScript

CSS

HTML

PowerShell 


📁 Repository Structure

`api/` - API endpoints and backend communication layers.

`brain/` - Core intelligence, model integrations, and reasoning logic.

`core/` - Central application logic and initialization scripts.

`frontend/` - User interface components (HTML, CSS, JavaScript).

`memory/` - Local memory management and context handling.

`tools/` - Built-in assistant tools and utilities.

`voice/` - Voice recognition and text-to-speech modules.

`tests/` - Test suites.

`config.py` - Configuration settings.

`main.py` - Main entry point to run the application.

`run_edith.ps1` - PowerShell script for launching EDITH easily on Windows.
